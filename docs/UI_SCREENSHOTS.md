- `public/images/Screenshot 2026-01-19 222242.png`
- `public/images/Screenshot 2026-01-19 224015.png`
- `public/images/Screenshot 2026-01-19 224152.png`

- `public/images/Screenshot 2026-01-19 224421.png`
- `public/images/Screenshot 2026-01-19 224455.png`

To capture fresh screenshots for this cross-platform release:
1. Mobile: run app on iOS/Android simulator and capture splash, auth, home, store, profile, settings.
2. Windows: run `npm run tauri:dev` in `windows` and capture home/store/profile/settings.
3. Save files in a dated folder, for example `docs/screenshots/2026-02-10/`.
